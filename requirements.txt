# Notes:
# - torch: get the CUDA build for your platform first if pip resolves
#   CPU-only (see https://pytorch.org/get-started/locally/), then
#   install the rest of this file.
# - kokoro pulls its own phonemizer (misaki) automatically.
# - transformers 5.x is REQUIRED-ish: the TTS eager path is chosen

#   behave differently under compile; eager still works.

# - torchvision: lockstep match for torch 2.5.1 is 0.20.1 (patch versions
#   must agree: 0.20.0 wants torch==2.5.0 and breaks resolution). Kaggle
#   pre-installs torchvision 0.25.0 (built for torch 2.10); with our torch
#   downgrade that combo crashes inside transformers' image_utils import
#   chain (register_fake torchvision::nms) and kills every model warm.
#   Pinning the matching version makes pip downgrade it deterministically.
#   (torchaudio stays version-mismatched on Kaggle but is unused by us.)
torchvision==0.20.1
triton==3.1.0
transformers==5.17.0
# - websockets: REQUIRED for uvicorn to accept WS /talk. Without it
#   uvicorn serves HTTP-only and every WS handshake 404s (the route still
#   registers, so /docs and route lists look fine — misleading).
fastapi==0.141.1

# - websockets: range (not a pin) so pip can satisfy langgraph-sdk (<17)
#   and uvicorn at the same time. Fresh resolver runs fail on an exact

#   Verified: WS /talk + bridge protocol tests pass on the resolved
#   version (see AGENTS.md). Do NOT re-pin exact without re-running
#   tests/src/test_server.py + tests/src/test_bridge.py.
