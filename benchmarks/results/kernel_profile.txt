notes:
- fused_qkv/fused_qkv_gqa: single Triton launch (x loaded once, 3 GEMVs fused) vs 3x F.linear (cuBLAS). Slight slowdown on 3050 for tiny GEMV (launch overhead dominates) but parity exact; wiring uses try/except fallback so live server never breaks.
- conv1d_silu_fwd: FIXED Triton `continue` rejection (now masked loads, no continue, no chained compare). Naive (N*Cout*Lout) programs x (Cin*K) scalar MACs is correct (parity) but much slower than cuDNN Winograd/GEMM for C=512 -- reported honestly. Fused SiLU saves a memory pass; use optional (fallback to torch) in production.
- in1d_silu: fused InstanceNorm(last-dim, fp32 accum) + SiLU, one pass, 2.53x faster than eager mean/var+silu.
- lstm_cell: single-launch full cell (4-gate GEMV + sigmoid/tanh + c/h update) vs nn.LSTMCell, 1.59x faster, parity 1e-07.
- parity refs: QKV vs F.linear; conv vs F.conv1d+silu; in1d vs (x-mean)/sqrt(var+eps)+silu and F.instance_norm+silu (3D check 2e-05); lstm vs nn.LSTMCell (bias_ih=b, bias_hh=0).
- TTS bf16 FAIL-LOUDLY threshold 1e-2: conv bf16 9.36e-04 (C=8 test) / 3.71e-03 (C=32) and in1d bf16 6.11e-03 -- both PASS (raise if >1e-2).
